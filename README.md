# PyroOptimised Music Bot

A Telegram Music Bot built with Python, Pyrogram and PyTgCalls.

## Features

- Telegram bot startup
- Assistant account support
- Voice chat integration
- Railway Docker deployment
- HTTP health endpoint

## Requirements

- Python 3.11
- FFmpeg
- Telegram API credentials
- Bot token
- Assistant session string

## Deployment

Deploy using the included Dockerfile.

Add the required environment variables in Railway.

Never share your bot token or session string.
